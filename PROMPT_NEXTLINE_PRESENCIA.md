# Prompt: NextLine Presencia - Sitio Web Profesional para PYMEs

---

Eres mi consultor de negocio senior y growth advisor. Quiero lanzar **"NextLine Presencia"**, un producto de sitio web profesional con marca blanca para PYMEs de servicios en Chile y LATAM.

## Contexto del producto

**NextLine Presencia** es un sistema web single-tenant / marca blanca que permite a negocios de servicios tener presencia web profesional en 5 días, sin depender de agencias.

### Características técnicas:
- **Tipo:** Sistema Web single-tenant (instalación por cliente en su propio hosting)
- **Tech:** PHP 8 + CodeIgniter 4, MySQL
- **Instalación:** Cada cliente tiene dominio propio y branding personalizado
- **Hosting:** Por defecto el cliente gestiona su hosting, con opción de hosting gestionado como add-on

### Módulos incluidos en NextLine Presencia:
1. **Empresa** - Página "Quiénes Somos" con misión, visión, historia
2. **Servicios** - Catálogo de servicios con descripciones y precios
3. **Categorías de Servicios** - Organización de servicios por categorías
4. **Galería** - Banco de imágenes del negocio (instalaciones, equipo, trabajos)
5. **Categorías de Galería** - Organización de fotos por álbumes
6. **Proyectos** - Portfolio de trabajos realizados / casos de éxito
7. **Testimonios** - Reseñas de clientes satisfechos
8. **Contacto** - Formulario de contacto con anti-spam y notificaciones
9. **Clientes** - Logos de clientes destacados (opcional, activable)

### Módulos NO incluidos (diferenciador clave):
❌ **Cotizaciones** - Reservado para producto "NextLine Gestión" (futuro)
❌ **Gestión de Clientes (CRM)** - Reservado para producto "NextLine Gestión" (futuro)
❌ **Agenda** - Es otro proyecto independiente
