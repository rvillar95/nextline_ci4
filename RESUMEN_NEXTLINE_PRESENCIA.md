## 🎯 NEXTLINE PRESENCIA - DEFINICIÓN

### **Qué ES:**
Sistema web profesional con marca blanca para PYMEs de servicios que necesitan presencia web en 5 días.

### **Módulos incluidos (9):**
1. ✅ Empresa (Quiénes somos)
2. ✅ Servicios + Categorías
3. ✅ Galería + Categorías
4. ✅ Proyectos (Portfolio)
5. ✅ Testimonios
6. ✅ Contacto (Formulario)
7. ✅ Clientes (Logos, opcional)

### **Módulos NO incluidos:**
- ❌ Cotizaciones → Reservado para "NextLine Gestión" (futuro)
- ❌ CRM de Clientes → Reservado para "NextLine Gestión"

### **ICP (Cliente Ideal):**
- Clínicas estéticas, barberías, talleres, spas, consultoras, constructoras pequeñas
- Sin sitio web o con sitio desactualizado
- Buscan profesionalismo sin complejidad
- Presupuesto: $400k-$900k año 1
