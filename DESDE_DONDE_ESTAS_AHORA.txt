🎯 SIGUIENTE PASO - OBTENER CREDENCIALES:
══════════════════════════════════════════════════════════════════════════════

1. En el menú lateral que estás viendo, haz clic en:
   
   📧 Sandboxes  ← HAZ CLIC AQUÍ

2. Verás una lista de "Inboxes" (buzones)
   
   Deberías ver algo como:
   ┌────────────────────────────────┐
   │ 📥 My Inbox                    │
   │ 0 messages                     │
   │ [View]                         │
   └────────────────────────────────┘

3. Haz clic en "My Inbox" o en el botón [View]

4. Una vez dentro, verás PESTAÑAS arriba:
   
   [ Messages ] [ SMTP Settings ] [ HTTP API ] [ Settings ]
   
   Haz clic en: SMTP Settings  ← HAZ CLIC AQUÍ

5. En SMTP Settings verás un dropdown que dice:
   
   "Select framework or language"
   
   Selecciona: "Other" o "Laravel/Symfony"

6. ¡AHÍ ESTÁN LAS CREDENCIALES! 🎉

💾 QUÉ HACER CON LAS CREDENCIALES:
══════════════════════════════════════════════════════════════════════════════

1. COPIA el Username (haz clic en el icono de copiar al lado)

2. COPIA el Password (haz clic en el icono de copiar al lado)

3. Ve a tu proyecto:
   C:\wamp64\www\codeigniter4\nextline_ci4\

4. Crea un archivo llamado: .env  (con punto al inicio)

5. Abre el archivo .env y pega esto:

═══════════════════════════════════════════════════════════════════════════════
CI_ENVIRONMENT = development

app.baseURL = 'http://localhost/codeigniter4/nextline_ci4/'

email.protocol = smtp
email.SMTPHost = smtp.mailtrap.io
email.SMTPUser = PEGA_TU_USERNAME_AQUI
email.SMTPPass = PEGA_TU_PASSWORD_AQUI
email.SMTPPort = 2525
email.SMTPCrypto = tls
email.mailType = html
email.charset = UTF-8
email.newline = "\r\n"
═══════════════════════════════════════════════════════════════════════════════

6. Reemplaza:
   - PEGA_TU_USERNAME_AQUI con el username que copiaste
   - PEGA_TU_PASSWORD_AQUI con el password que copiaste

7. GUARDA el archivo .env

8. REINICIA WAMP (Stop All Services → Start All Services)

9. Prueba el formulario:
   http://localhost/codeigniter4/nextline_ci4/contacto

10. Vuelve a Mailtrap → Sandboxes → My Inbox → Messages
    ¡Verás el email ahí! 🎉
